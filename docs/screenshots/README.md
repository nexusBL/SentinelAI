# Screenshot Placeholders

Add real dashboard screenshots here before publishing a final demo gallery.

Recommended filenames:

- `overview.png`
- `new-run.png`
- `run-detail.png`
- `reports.png`
- `graph-trace.png`

Suggested capture order:

1. Overview page with recent runs visible
2. New Run page with the execution form
3. Run Detail page with screenshots and traces expanded
4. Reports page with HTML and JSON report links
5. Run Detail graph trace or metrics section

These files are optional. The README intentionally does not hardcode missing image links.
